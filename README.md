# Part 1 — Product Position & Vision

## Product Position

For me, Kivi is a communication companion that stays with you on your desktop and helps you communicate faster using your voice. It can convert speech into text, save what you said, translate it into different languages and speak the result back to you. I see Kivi being useful for people who want to save time and communicate more easily without constantly switching between different applications.

## Product Vision

For me, Kivi should become a communication companion that is always available when I need it. Instead of opening different applications for speech-to-text, translation or other communication tasks, Kivi can stay on the desktop and help me directly while I am already working. I want Kivi to feel like a small companion rather than just another software tool. In the future, I see Kivi growing beyond communication and becoming an assistant that can understand what I need and help me perform different tasks on my computer. At the same time, I don't want Kivi to become complicated or filled with unnecessary features. It should remain simple, useful and focused on helping people communicate and save time.

# Part 2 — Redesign Styles

For Part 2, I focused on making the Kivi experience more attractive, interactive and easy to understand.

First, I added a **loading animation** so that when Kivi starts, it feels more polished instead of just opening suddenly.

I also worked on the **Kivi desktop companion**. Kivi is shown as a stylish bird that stays on the desktop and feels like a small companion while using the computer. I wanted the bird to have personality instead of feeling like a normal software icon.

I added an **application tour** so that a new user can understand what Kivi is, what it can do and how to use the different parts of the application without needing someone to explain it. The tour is interactive and uses visuals so the user can learn the product by interacting with it.

I also worked on the **UI and visual experience** to make the application feel more polished and engaging while keeping the Kivi identity and bird.

Another feature I added is the **talk-back option**, where Kivi can speak the output back to the user in a selected Indian language. This makes the communication experience more useful when the user wants to hear the translated or generated text instead of only reading it.

Overall, my Part 2 redesign is about improving the first experience and making Kivi feel more like a real desktop companion through the loading animation, stylish bird companion, application tour, interactive UI, visuals and Indian-language talk-back experience.
